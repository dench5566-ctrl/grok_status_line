# Правила проекта grok_status_line

Программа и формат строки описаны в `README.md`. `statusline.py` рисует строку,
`install.py` устанавливает её в пользовательскую конфигурацию Grok.

- Формат лимита, смысл процентов и направление полоски не менять без просьбы.
- `~/.grok/auth.json` содержит ключ: не печатать, не копировать и не коммитить.
- Кэш `~/.grok/statusline-billing.json` не добавлять в репозиторий.
- Установщик меняет только таблицу `[ui.status_line]` в
  `~/.grok/config.toml`; остальные настройки сохранять байт-в-байт.
- Не запускать установку, если задача касается только кода или документации.
- Сетевой запрос допустим только по правилам триггеров и кэша из README.

После изменения проверить синтетическим JSON из раздела «Проверка» README.
Перед коммитом убедиться, что в diff нет ключа, содержимого auth-файла и
пользовательской конфигурации.
